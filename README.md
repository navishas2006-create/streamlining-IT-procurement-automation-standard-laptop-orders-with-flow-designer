# Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer

Working college project using Python Flask + SQLite.

## Features
- Employee laptop request
- Standard laptop validation concept
- Manager approval/rejection
- Automatic procurement task creation
- Procurement completion
- Status tracking
- Admin dashboard
- SQLite database
- Flow Designer-style automation implemented in application logic

## Run
1. Install Python 3.10+.
2. Open terminal in this folder.
3. Run `pip install -r requirements.txt`
4. Run `python app.py`
5. Open http://127.0.0.1:5000

Demo users:
- John — Employee
- Manager A — Manager
- Procurement Team — Procurement
- Admin — Admin

## Workflow
Request → Manager Approval → Procurement Task → Completion → Notification

This is a standalone academic implementation inspired by ServiceNow Flow Designer concepts; it is not an official ServiceNow update-set export.
